Why it is small on purpose

The whole extension is under 5 KiB. It has no analytics, no background tracking and no account system. It opens a compact popup that talks to the same public site you already use.

The developer declares that data is not sold to third parties and is not used for creditworthiness or lending decisions.

Install in three steps

  1. Open the Digital Infohub page in the Chrome Web Store.
  2. Choose Add to Chrome and confirm the prompt.
  3. Click the puzzle icon in Chrome's toolbar, then pin Digital Infohub so it is always one click away.

Extension questions

Does it work in Edge, Brave or other Chromium browsers?

Yes. Any browser that can install from the Chrome Web Store — Edge, Brave, Vivaldi, Opera and Arc — can add it the same way. Firefox and Safari use a different extension format.

Do I need an account?

No. There is no sign-in and no profile. The popup reads public content from digitalinfohub.net.

What permissions does it use?

The listing is deliberately minimal: it opens a popup and loads public pages. There is no background browsing history collection.

Is there a mobile version?

Extensions are desktop-only, but the site installs as a home-screen app on iOS and Android. See the install page.

How do I remove it?

Right-click the icon and choose Remove from Chrome, or open chrome://extensions and remove it there.

Creative Studio · Documents

PDF Toolbox

Merge contracts, split a scan into single pages, or make a bloated PDF small enough to email. Everything happens in this tab: the files are read by your browser and never uploaded to a server.

New Merge · Split · Compress No upload No watermark
No files yet.

This rebuilds each page as a high-quality image, which is what makes scans and exported decks dramatically smaller. Text layers are flattened, so keep the original if you still need selectable text or form fields.

Which button do I need?

Three different problems, three different fixes.

MergeJoining a signed contract with its appendix, or turning a month of invoices into one file. Pages keep their original order and quality.
SplitExtracting pages 3–7 for a colleague, or separating a scanned bundle into one file per page. Nothing is re-encoded, so text and links survive.
CompressFixing the “file too large to email” problem. Re-encoding the page images is what actually shrinks a scan; moving the same bytes around does not.

Privacy and limits

What happens to the file you just opened.

Nothing is uploadedParsing, merging, splitting and re-encoding all run in this tab using JavaScript. There is no server to send the file to.
Encrypted filesPDFs with a password cannot be opened in the browser. Remove the password in a desktop reader first, then process it here.
Big documentsCompression is the heavy operation: a 60-page scan can take a minute. Keep the tab open until the download appears.
